# Jack living portrait: the 58 pictures

Drop each file into `public/jack-faces/` named exactly as below (`rest.png`, `closed.png`, ...).
Rules: same man, same framing, same size, **transparent background**, pixel-aligned with `rest.png`
(generate each one as an edit of `rest.png`, changing only what is described). Missing files are skipped,
so you can add them in batches. Without `rest.png` the portrait stays a still image.
